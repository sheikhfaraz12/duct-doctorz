# Duct Doctorz

Run locally with Live Server at `/`, `/?city=on`, `/?city=on&loc=ottawa`, or `/?city=ab&loc=edmonton`.

To add a location, add an entry in `cities.json` and add its province to the rewrites in `vercel.json` if it is new. Replace the animation frames in `assets/frames/` and update `FRAME_COUNT` in `script.js` to match. Deploy through GitHub to Vercel and attach `ductdoctorz.com`.
